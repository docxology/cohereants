# Frequently asked questions

## Where do I edit the paper?

Edit [the canonical source](manuscript/README.md). The tracked files in
`output/manuscript/` are resolved release artifacts.

## Do the models establish infrared olfaction?

The [empirical literature review](manuscript/07_empirical_studies.md) describes
documented infrared responses in particular organisms and contexts. The full
olfaction hypothesis remains open. The finite model outputs illustrate
assumptions, numerical bounds, and testable predictions.

## How do I check my local changes?

Use the [quick start](quickstart.md) for tests and the
[pinned render](rendering_pipeline.md) for PDF and HTML.
