This is the editable manuscript by Tucker Chambers and Daniel A. Friedman.
Start with the [abstract](00_abstract.md), then read the
[methodology](02_methodology.md), [modeled results](03_experimental_results.md),
and [empirical literature review](07_empirical_studies.md). The discussion and
conclusion describe the open hypothesis and proposed falsifiers. The appendices
give model details and the final section collects references.

and [bibliography](references.bib) are the maintained render inputs. See the
[offline render instructions](../rendering_pipeline.md) and
[editorial conventions](AGENTS.md). Tokenized values refer to modeled or
configured quantities. The [versioned deposit](https://zenodo.org/records/20450970)
records the archived release.
