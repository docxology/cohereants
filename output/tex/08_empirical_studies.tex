\section{Empirical Studies}\label{sec:empirical_studies}

\subsection{Introduction}\label{introduction}

This section summarizes empirical evidence relevant to IR‑based
olfaction, organized by domain: spectroscopy, morphology,
neurophysiology, behavior, and computational modeling. For each entry we
list key quantitative results and the \passthrough{\lstinline!src/!}
code anchors used to reproduce or benchmark findings.

\textbf{Analytical framing}: Evidence is evaluated using the
repository's deterministic computational tools (Fermi Estimation,
meta‑material analysis, environmental channel models). Referenced
artifacts are reproducible via provided scripts (e.g.,
\passthrough{\lstinline!scripts/generate\_integrated\_analysis.py!},
\passthrough{\lstinline!scripts/generate\_research\_figures.py!}) and
depend only on \passthrough{\lstinline!src/!} core logic.

\textbf{Evidence integration}: Each empirical claim maps to a
reproducible code path and validation tests, enabling cross‑domain
synthesis and direct experimental follow‑up.

\subsubsection{Isotope Discrimination
Studies}\label{isotope-discrimination-studies}

\begin{itemize}
\tightlist
\item
  \textbf{Citation}:
  \href{https://www.pnas.org/doi/10.1073/pnas.1012293108}{Turin et
  al.~(2011) - PNAS}
\item
  \textbf{Species/Context}: \emph{Drosophila melanogaster}; behavioral
  conditioning
\item
  \textbf{Methods}: PER conditioning with deuterated vs.~non‑deuterated
  acetophenone; N ≥ 100 per condition; p \textless{} 0.001

    cm\(^{-1}\)
  \item
    Frequency ratio: predicted 0.707; observed 0.71 ± 0.02
  \end{itemize}
\item
  \textbf{Implications}: Strong evidence for vibrational sensitivity
  beyond stereochemical recognition
