Points}\label{sec:app_detection_limits}

\subsection{Objective}\label{objective}

Comprehensive detection theory analysis including ROC curves,
sensitivity analysis, operating regions, and noise floor
characterization for IR olfactory detection systems.

    - Thermal noise limited detection
  \item
    \passthrough{\lstinline!roc\_analysis(signal\_power, noise\_power)!}
    - ROC curves and optimal thresholds
  \item

    - Performance curves and MDS
  \item
    \passthrough{\lstinline!sensitivity\_analysis(power\_range, temp\_range, param\_variations)!}
    - Parameter sensitivity
  \item
    \passthrough{\lstinline!operating\_regions\_analysis(power\_range, temp\_range)!}
    - SNR contours in operating space
  \item
    \passthrough{\lstinline!noise\_floor\_analysis(freq\_range, temperature\_k)!}

  \item
