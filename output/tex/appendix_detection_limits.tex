\section{Appendix C: Detection Limits and Operating
Points}\label{sec:app_detection_limits}

\subsection{Objective}\label{objective}

Comprehensive detection‑theory analysis with validation against
electrophysiological studies: ROC curves for 1-5 ms latency detection,
sensitivity analysis for sub-10 ms ORN responses, operating regions in
power-temperature space, and noise‑floor characterization distinguishing
electromagnetic from thermal effects for IR olfactory detection systems.
