\section{Appendix E: Spectral Unmixing and
Classification}\label{sec:app_spectral_unmixing}

\subsection{Objective}\label{objective}

Comprehensive spectral analysis: realistic CHC data generation, feature
extraction, unmixing (NMF, VCA, ICA), and multi‑algorithm classification
with deterministic evaluation.

\subsection{Methods (src)}\label{methods-src}

\begin{itemize}
\tightlist
\item
  \passthrough{\lstinline!src/case\_studies/spectral\_unmixing.py!}

  \begin{itemize}
  \tightlist
  \item
    \passthrough{\lstinline!generate\_realistic\_chc\_spectra(n\_compounds: int, n\_wavelengths: int, seed: int=42) -> dict!}
    --- synthetic CHC spectra with ground truth
  \item
    \passthrough{\lstinline!nmf\_unmix(spectra: np.ndarray, n\_components: int, seed: int=42) -> (W, H)!}
    --- deterministic NMF
  \item
    \passthrough{\lstinline!vertex\_component\_analysis(spectra: np.ndarray, n\_endmembers: int) -> np.ndarray!}
    --- VCA endmember extraction
  \item
    \passthrough{\lstinline!independent\_component\_analysis\_spectra(spectra: np.ndarray, n\_components: int) -> np.ndarray!}
    --- ICA separation
  \item
    \passthrough{\lstinline!spectral\_feature\_extraction(spectra: np.ndarray, wavelengths: np.ndarray, method: str='peaks') -> dict!}
    --- peaks, derivatives, PCA, statistical features
  \item
    \passthrough{\lstinline!advanced\_classification\_suite(features: np.ndarray, labels: np.ndarray) -> dict!}
    --- multi‑algorithm benchmark
  \item
    \passthrough{\lstinline!performance\_metrics\_comprehensive(y\_true: np.ndarray, y\_pred: np.ndarray, y\_prob: Optional[np.ndarray]=None) -> dict!}
  \item
    \passthrough{\lstinline!lda\_baseline(features: np.ndarray, labels: np.ndarray, seed: int=42) -> dict!}
    --- closed‑form LDA baseline
  \end{itemize}
\end{itemize}
