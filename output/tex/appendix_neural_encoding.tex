\section{Appendix D: Neural Encoding Efficiency on
Time-Series}\label{sec:app_neural_encoding}

\subsection{Objective}\label{objective}

Comprehensive neural encoding analysis including spike train generation,
temporal dynamics, population coding, mutual information, and adaptation
mechanisms for olfactory receptor neurons.

\subsection{Methods (src)}\label{methods-src}

\begin{itemize}
\tightlist
\item
  \passthrough{\lstinline!src/case\_studies/neural\_encoding.py!}

  \begin{itemize}
  \tightlist
  \item
    \passthrough{\lstinline!generate\_spike\_trains(stimuli, dt, baseline\_rate, max\_rate, dynamics)!}
    - Realistic spike generation
  \item
    \passthrough{\lstinline!analyze\_spike\_train\_statistics(spike\_data)!}
    - ISI, CV, Fano factor analysis
  \item
    \passthrough{\lstinline!temporal\_coding\_analysis(spike\_data, stimulus\_times)!}
    - Latency and precision metrics
  \item
    \passthrough{\lstinline!population\_coding\_analysis(population\_responses, labels)!}
    - PCA, LDA, correlations
  \item
    \passthrough{\lstinline!mutual\_information\_analysis(responses, stimuli)!}
    - Information theory metrics
  \item
    \passthrough{\lstinline!odor\_discrimination\_analysis(responses, odor\_ids, time\_windows)!}
    - Discrimination performance
  \item
    \passthrough{\lstinline!adaptation\_dynamics\_analysis(spike\_data, stimulus\_duration)!}
    - Adaptation characterization
  \item
    \passthrough{\lstinline!information\_rate\_time\_series(responses, dt\_s, noise\_std)!}
    - Channel capacity estimation
  \item
    \passthrough{\lstinline!rate\_coding\_metrics(responses, labels)!} -
    Basic discriminability metrics
  \end{itemize}
\end{itemize}
