\section{Appendix A: Sensilla Array Directionality and Beam
Patterns}\label{sec:app_sensilla_array}

\subsection{Objective}\label{objective}

Electromagnetic antenna modeling for sensilla arrays with validation
against peer-reviewed morphometric data: circular/log‑periodic designs
based on real insect antenna structures, element patterns, mutual
coupling, 2D radiation patterns, morphology analysis across 500+
specimens, and frequency‑response characterization for directional
olfactory detection.
