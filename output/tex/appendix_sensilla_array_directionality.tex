\section{Appendix A: Sensilla Array Directionality and Beam
Patterns}\label{sec:app_sensilla_array}

\subsection{Objective}\label{objective}

Comprehensive electromagnetic antenna modeling for sensilla arrays
including circular array design, element pattern modeling, mutual
coupling effects, 2D radiation patterns, morphology analysis, and
frequency response characterization for directional olfactory detection.
